01 — Context

The Challenge

Although bottlers were actively promoting the app and encouraging merchandisers to install it, user engagement remained critically low despite the app's clear benefits. The business was struggling to manage merchandising across remote European locations — directly impacting approximately 5% of sales.

01

Low user engagement despite active promotion by bottlers and clear reward incentives

02

Inability to manage merchandising across remote locations — ~5% sales impact

03

Unclear instructions and opaque scoring system causing user frustration and drop-off

02 — Discovery

Research Approach

Real users were store owners and merchandisers in remote European locations. In-person testing wasn't possible, so we set up remote usability sessions over Microsoft Teams — recording each call while participants used the app live on their own devices.

Each session covered 5 tasks and ran 30–40 minutes with 5 users. We measured task success rate, time on task, total clicks, and System Usability Scale (SUS) score.

Tasks assigned: Sign Up · Capture Scene & Submit · Check Best Result & Return to Home · Update Profile · Check Result Image & SKU Tab

03 — Usability Testing

Usability Test Metrics

All values are averages across 5 users. SUS scores above 80 are considered good; below 60 indicate significant usability problems.

Task Success Rate Time on Task Clicks SUS Score
Sign Up 100% 3 min 5 94
Capture Scene & Submit 80% 5 min 12 76
Check Best Result & Go to Home 60% 4 min 6 62
Update Profile & Check Details 100% 5 min 10 85
Check Result Image & SKU Tab 40% 5 min 20 38

The Check Result Image & SKU Tab task had a 40% success rate and a SUS score of 38 — well below the acceptable threshold. This became the primary redesign focus.

04 — Qualitative Research

User Interviews

We interviewed 3 users in depth to understand their daily context, motivations, and frustrations with the app. Common patterns emerged across all three around clarity of instructions, scoring transparency, and reward accessibility.

U1
User 1 — Frequent Rewards App User Power User ▾
Experience

Heard about the app from a friend. Opens it while out to capture assets. Waits for score results.

Finds the interface clean and easy to navigate, but often unsure if assets were captured correctly — wishes for clearer in-context feedback.

Pain Points

Hasn't earned many rewards — difficulty achieving high enough scores. Wants more variety in reward options.

Key Requests

More guidance for accurate capture · Progress tracker · Leaderboard to compare with other users

U2
User 2 — New to Rewards Apps Casual User ▾
Experience

Found the app in the store while browsing reward apps. Finds basic capture straightforward, but scoring system is opaque and confusing.

Pain Points

Doesn't understand how the scoring system works. Difficult to achieve scores high enough for rewards — discouraging.

Key Requests

More transparency around scoring · More frequent low-barrier reward opportunities · Clearer visual prompts during capture

U3
User 3 — Avid Rewards Collector Engaged User ▾
Experience

Actively seeks reward apps. Finds capture easy but is sometimes unsure if assets were captured correctly — leads to frustration and resubmission.

Pain Points

Has earned some rewards but struggles to reach higher-value tiers. Finds navigation unintuitive in certain flows.

Key Requests

Better capture guidance · Progress tracker to see performance vs. peers · More intuitive navigation structure

11 — Prototype Testing

User Testing & Opportunities

Prototype testing sessions with a diverse group — store owners, managers, and inventory staff — surfaced specific usability strengths and actionable improvement areas across 8 functional categories.

01 Onboarding Experience ▾

Participants found the onboarding process intuitive and easy to follow. A few users suggested adding more visual cues or tooltips for additional guidance during initial setup.

✓ Add contextual tooltips to onboarding
02 Asset Capture ▾

Users reported high satisfaction with asset capture — praising its simplicity and effectiveness. Clear prompts helped users capture accurately, though some noted image recognition accuracy needed improvement.

✓ Improve image recognition accuracy
03 Redeeming Rewards ▾

No major issues with redeeming rewards — the process was straightforward and seamless. Users suggested streamlining reward selection and providing more detailed information about redemption options.

✓ Streamline reward selection flow
04 Navigation & Usability ▾

Navigation found intuitive overall, but a few participants suggested organizing the navigation menu more logically for improved accessibility to key features.

✓ Reorganize navigation menu hierarchy
05 Notifications ▾

Users appreciated notification management but noted occasional delivery delays. Reliability of the notification system needs improvement.

✓ Improve notification delivery reliability
06 Profile Management ▾

Profile section was easy to use. Users requested additional customization options for notification settings and account preferences.

✓ Add notification preference controls
07 Search Functionality ▾

Search was effective for finding outlets and products. Users suggested adding filters and sorting options to refine results further.

✓ Add filters & sort to search
08 Camera Functionality ▾

No difficulty using the camera feature. Clear instructions and visual feedback helped users complete capture efficiently. No issues recorded.

✓ Maintain current camera UX patterns

12 — Recommendations

Design Recommendations

Based on the full research and testing cycle, six prioritized improvements were proposed to the product team.

🎯

Improve image recognition accuracy to ensure valid asset capture results and reduce resubmissions

🎁

Streamline reward selection and provide clearer information about redemption options and tiers

🧭

Reorganize the navigation menu for improved logical flow and accessibility to key features

🔔

Enhance notification delivery reliability to ensure timely, dependable alerts for earned rewards

⚙️

Add customization options for notification settings and account preferences in profile section

🔍

Add filters and sorting options to search results for faster outlet and product discovery
